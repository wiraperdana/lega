Memeriksa sepuluh lokasi cache

Browser, aplikasi rapat, pengelola paket, dan hasil build. Lokasi yang tidak ada di Mac Anda disembunyikan.

Download Lega untuk Mac

Download untuk Apple Silicon Download untuk Intel

Versi 1.0.0, DMG 1,5 MB, macOS 15 ke atas. Jenis chip Mac Anda tertulis di menu Apple, About This Mac.

  1. Seret Lega ke Applications

    Buka file DMG, lalu seret ikon Lega ke folder Applications.

  2. Izinkan saat pertama dibuka

    macOS menahan Lega sekali. Buka System Settings, Privacy & Security, lalu klik Open Anyway.

  3. Bersihkan dari menu bar

    Ikon Lega tetap di menu bar dan ikut menyala setiap Mac dinyalakan.

Tanya jawab tentang Lega

Apa saja yang dihapus tombol utama?

Hanya cache yang dibuat ulang sendiri: browser, Zoom, Homebrew, npm, pip, uv, Go, node-gyp, dan versi lama Codex.

Bagaimana kalau aplikasinya sedang terbuka?

Cache aplikasi itu dilewati, jadi Anda tidak perlu menutupnya atau merestart Mac.

Apakah file saya bisa hilang?

File pribadi dipindah ke Trash dan masih bisa dikembalikan. Data besar selalu menunggu persetujuan Anda.

Kenapa macOS memblokirnya saat dibuka?

Lega belum ditandatangani Developer ID Apple. Buka System Settings, Privacy & Security, lalu klik Open Anyway. Cukup sekali.

Mac apa saja yang didukung?

macOS 15 Sequoia ke atas, di Apple Silicon maupun Intel.

Berapa harganya?

Gratis. Kode sumbernya terbuka dengan lisensi MIT.
